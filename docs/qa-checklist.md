# QA-чеклист: MSC-флаги и связанные фичи

Логи смотрим: Настройки → Логи (Talker). Ошибки вида `[settings]`, `[chats]`, `[push]`, `[matrix]`.

## 0. Регрессия базы (после любых изменений)

- [ ] Вход, список чатов грузится, сообщения отправляются и приходят
- [ ] Пуш приходит на свернутое приложение (обычный чат)
- [ ] `flutter test test/` зеленый, `dart analyze` без ошибок в измененных файлах

## 1. Уведомления: приглашения (MSC3664 — шум в verbose)

- [ ] Настройки → Уведомления: строка «Реакции» отсутствует, осталось только «Приглашения»
- [ ] Тоггл «Приглашения» двигается без ошибок в логе
- [ ] `Unknown push condition: im.nheko.msc3664.related_event_match` виден только в verbose, не в debug

## 2. Стук и превью (MSC3266)

Каталог (обе платформы):
- [ ] Тап по комнате → bottom-sheet: аватар, имя, топик, число участников, бейдж (Открытая / Вход по заявке / Закрытая)
- [ ] Публичная → кнопка «Войти» → открывается чат
- [ ] Knock → кнопка «Стучаться» → после тапа «Заявка отправлена» + «Отозвать заявку»
- [ ] Invite/private → текст «Закрытая комната», кнопок нет
- [ ] Отзыв заявки возвращает кнопку «Стучаться»

Ссылки и alias:
- [ ] `matrix.to/#/!room:server` на knock-комнату → шит, а не молчаливый фейл join
- [ ] Ссылка на комнату, где уже состоишь → сразу открывается чат

Сервер БЕЗ summary (старый):
- [ ] Каталог работает, шит строится из данных каталога без превью
- [ ] Ссылка → прямой join как раньше

Админка:
- [ ] После стука в инфо комнаты появляется «Заявки (1)» (обе платформы)
- [ ] Экран заявок: имя в заголовке, ID в подзаголовке, галочка впускает (стучащийся появляется в участниках), крестик отклоняет (заявка пропадает)
- [ ] Заявок нет → пункта «Заявки» нет
- [ ] Комната со статусом knock у стучащегося показывает «Заявка отправлена — дождитесь» вместо «Вы покинули чат»

## 3. Только упоминания (MSC4028, шифрованный чат)

Предусловие: сервер с флагом, шифрованная комната из 3+ человек.
- [ ] Инфо комнаты → секция «Уведомления»: сегмент Все / Упоминания (только в шифрованных при поддержке)
- [ ] Режим «Упоминания»: обычное сообщение → пуша НЕТ, сообщение в чате есть
- [ ] Сообщение с `@твой ID` → пуш есть
- [ ] Сообщение с твоим отображаемым именем в тексте → пуш есть
- [ ] Сообщение с `@room` → пуш есть
- [ ] Сервер БЕЗ флага → секции «Уведомления» нет вообще
- [ ] Переключение режима сохраняется после перезахода в инфо

## 4. Статус «занят» (MSC3026)

- [ ] Профиль → секция «Статус»: В сети / Занят / Невидимка (обе платформы)
- [ ] «Занят» держится дольше минуты (не слетает на синке)
- [ ] Со второго аккаунта: шапка лички показывает «Занят», в списке точка оранжевая/tertiary
- [ ] «Невидимка»: со второго аккаунта ты офлайн («был(а) в сети ...»)
- [ ] Возврат «В сети» работает
- [ ] Сервер с явным отказом флага → секция «Статус» скрыта

## 5. Причины инвайтов (MSC4491)

- [ ] Инвайт с причиной → в карточке приглашения виден текст причины (обе платформы)
- [ ] Инвайт без причины → «Вас пригласили в чат» как раньше
- [ ] Инфо комнаты → Пригласить → ввод ID + причина → у второго аккаунта карточка с этой причиной
- [ ] Приглашение без причины тоже уходит нормально

## 6. Кастомные поля профиля (MSC4133)

Предусловие: сервер с флагом + настроенные поля (или свободный ввод).
- [ ] Профиль → секция «Дополнительно» со строками полей (обе платформы)
- [ ] Тап по разрешенному полю → правка → сохраняется, видно со второго аккаунта/другого клиента
- [ ] Пустое значение при правке удаляет поле
- [ ] «Добавить поле»: неверный ключ (без точки, кириллица, `m.*`) → ошибка в шите, запроса нет
- [ ] Ключ вне allowed-списка сервера → «Сервер не разрешает это поле»
- [ ] Сервер БЕЗ флага → секции нет, ошибок в логе нет

## 7. Без legacy-упоминаний (MSC4210)

Твой сервер С флагом:
- [ ] Упоминание `@твой ID` от Element/Fluffy → пуш приходит
- [ ] Упоминание тебя по отображаемому имени → пуш приходит
- [ ] Простое совпадение ника в тексте без `@` → пуша НЕТ (это и есть смысл флага)
- [ ] В логе нет `restore mention rule failed` каждый синк
- [ ] Ты упоминаешь другого → у него пуш (наши сообщения несут `m.mentions`)

Чужой сервер БЕЗ флага:
- [ ] Всё работает как раньше, включая пуши по совпадению ника
- [ ] Ошибок в логе нет

## 8. Удаленное у модераторов (MSC2815)

Флаг на сервере ВКЛ, ты модератор:
- [ ] Удаленное сообщение: плашка + кто удалил + «видно модераторам» + текст курсивом (обе платформы)
- [ ] Обычный участник видит только «Сообщение удалено»
- [ ] Включено «Скрывать удаленные» → скрыто у всех, включая модераторов

Флаг на сервере ВЫКЛ (твое решение):
- [ ] Модераторы видят обычное «Сообщение удалено», текста нет нигде

## 9. Настройка комнаты + инфо (макет)

Права есть (админ тестовой комнаты):
- [ ] Карандаш у названия → переименование применяется, видно со второго аккаунта
- [ ] Описание: правка + «Добавить описание» когда пусто
- [ ] Аватар: тап → выбор картинки → меняется (обе платформы)
- [ ] Правило входа: Открытая / По заявкам / По приглашениям переключается, бейдж в шапке обновляется
- [ ] Пригласить: поиск находит юзера, выбор + причина → инвайт доходит
- [ ] Пригласить: ручной ввод `@user:server` без поиска → инвайт доходит
- [ ] Ошибка (нет прав/сети) → снекбар, шит не висит

Прав НЕТ (обычный участник):
- [ ] Карандашей, «Пригласить», «Правила входа» нет вообще
- [ ] Заявки видны только если есть стучащиеся (ты их впустить не сможешь — acceptance упадет? проверить: кнопок быть не должно без прав. Сейчас: заявки видны всем по knockCount. Если ты не модер — галочка вернет ошибку. Отметить как известное ограничение)

## 10. Дегидрация (MSC3814, регрессия)

- [ ] Вход с нового устройства + ввод recovery key → история расшифровывается
- [ ] Тоггл в экспериментальных настройках переключается
